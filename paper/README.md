# paper/

Финальная статья и связанные материалы.

- `draft.md` — черновик статьи в Markdown (наполняется на 2-й неделе)
- `references.bib` — список литературы в BibTeX-формате
- `figures/` — все рисунки, графики и таблицы для финальной версии

При финальной сборке статьи Markdown конвертируется в Word (.docx) для подачи в журнал.
