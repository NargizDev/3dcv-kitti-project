# Синтетическая аугментация для моно-3D-локализации в дорожных сценах

**Авторы:** Исмаилова Наргиз, Донецкая Елена

---
## 1. О чём проект

### Тема статьи
**«Сравнительный анализ влияния синтетических дорожных данных на качество моно-3D-локализации объектов»**

### Научная задача
Исследовать, насколько синтетические данные (Virtual KITTI 2) помогают улучшить пространственную локализацию объектов в дорожных сценах, когда используется пайплайн из двух нейросетевых моделей: 2D-детектора (YOLOv8) и моно-оценки глубины (Depth Anything v2).

### Ключевые исследовательские вопросы
1. Насколько точно можно определить 3D-координаты объектов через комбинацию 2D-детекции и моно-depth?
2. Какой вклад вносят синтетические данные при разных пропорциях смешивания (real-only / mixed / synth-only)?
3. Каков domain gap между реальными и синтетическими дорожными сценами для каждого компонента пайплайна?

## 2. Техническая архитектура

### Пайплайн «Lift-to-3D»

```
                    RGB-изображение (KITTI / Virtual KITTI 2)
                                  │
              ┌───────────────────┴───────────────────┐
              ▼                                       ▼
    ┌─────────────────┐                   ┌──────────────────────┐
    │    YOLOv8       │                   │   Depth Anything v2  │
    │  2D-детектор    │                   │   моно-depth         │
    │  (Track A)      │                   │   (Track B)          │
    └────────┬────────┘                   └──────────┬───────────┘
             │                                       │
             ▼                                       ▼
       2D bounding boxes                       Depth map
       + классы                                (метрическая глубина)
             │                                       │
             └───────────────────┬───────────────────┘
                                 ▼
                  ┌──────────────────────────────┐
                  │   Lift-to-3D алгоритм        │
                  │   • извлечение глубины bbox  │
                  │   • back-projection через    │
                  │     калибровочную матрицу K  │
                  │   • восстановление (X, Y, Z) │
                  └──────────────┬───────────────┘
                                 ▼
                       3D-координаты объектов
                                 │
                                 ▼
                  ┌──────────────────────────────┐
                  │   Метрики оценки             │
                  │   • mean depth error         │
                  │   • 3D IoU с GT bbox         │
                  │   • localization accuracy    │
                  └──────────────────────────────┘
```

### Почему именно этот подход
- **Использует pre-trained модели** — не нужно обучать с нуля, экономит время и GPU-ресурсы
- **Запускается на бесплатном Colab** (T4, 16 GB VRAM)
- **Каждый компонент тестируется отдельно** — удобно для анализа и распределения работы
- **Ложится на программу курса** — Лекция 3 покрывает оба компонента

## 3. Данные

### Реальные данные: KITTI 3D Object Detection
- **Источник:** https://www.cvlibs.net/datasets/kitti/eval_object.php?obj_benchmark=3d
- **Объём:** 7481 train + 7518 test изображений
- **Что используем:** левые RGB-изображения (12 GB), labels (5 MB), calibration (16 MB)
- **GT-аннотации:** 3D bounding boxes для классов Car, Pedestrian, Cyclist
- **Фокус:** класс Car (больше всего примеров)

### Синтетические данные: Virtual KITTI 2
- **Источник:** https://europe.naverlabs.com/research/computer-vision/proxy-virtual-worlds-vkitti-2/
- **Объём:** ~21 000 кадров, 5 сцен × 6 вариаций (clone, fog, morning, overcast, rain, sunset)
- **Что используем:** RGB, depth maps, 3D bbox, instance masks
- **Особенность:** фотореалистичный движок Unity, идеальный GT для каждого пикселя
- **Преимущество перед CARLA:** не требует мощного GPU для генерации, всё уже готово

## 5. Организация Google Drive

Создать общую папку `3dcv-project` со следующей структурой:

```
3dcv-project/
├── data/
│   ├── kitti/           ← Track A: реальные данные
│   └── vkitti2/         ← Track B: синтетические данные
│
├── code/
│   ├── track_a/         ← Track A: ноутбуки и скрипты Наргиз
│   ├── track_b/         ← Track B: ноутбуки и скрипты Лены
│   └── shared/          ← общие модули (loader, metrics)
│
├── checkpoints/         ← веса моделей
│
├── results/
│   ├── track_a/         ← выходы YOLO + lift-to-3D
│   ├── track_b/         ← depth maps + метрики
│   └── joint/           ← финальные таблицы и графики
│
├── paper/
│   ├── draft.md         ← черновик статьи
│   ├── figures/         ← графики и визуализации
│   └── references.bib   ← список литературы
│
└── README.md            ← этот файл (для справки)
```
